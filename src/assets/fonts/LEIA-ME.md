# Fonte Satoshi

O design system usa **Satoshi**. O arquivo `Satoshi-Variable.woff2` não vem no repositório
porque a licença (ITF Free Font License) proíbe redistribuir. Baixar é grátis:

1. https://www.fontshare.com/fonts/satoshi -> **Download family**
2. Do zip, copie `Satoshi_Complete/Fonts/WEB/fonts/Satoshi-Variable.woff2` para esta pasta.
3. Não renomeie, não converta e não faça subset (a licença proíbe modificar).

Sem o arquivo o app usa Inter / fonte do sistema. Funciona, mas não é o visual aprovado.
